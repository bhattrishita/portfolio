# Portfolio Customization Guide

## 🎯 Quick Start

Your new portfolio is ready! Here's what you need to customize:

## 📝 Essential Information to Update

### 1. Personal Information
**File: `src/components/Hero.tsx`**
- Line 55: Change "Rishita" to your name
- Line 65: Update your title and university
- Line 69: Update your description
- Lines 16-30: Update social media links

### 2. Experience Section
**File: `src/components/Experience.tsx`**
- Lines 7-50: Replace the experience array with your actual work experience
- Update company names, positions, dates, and descriptions
- Modify the skills section (lines 120-140) with your technologies

### 3. Projects Section
**File: `src/components/Projects.tsx`**
- Lines 7-60: Replace with your actual projects
- Update project titles, descriptions, and technologies
- Add your GitHub and live demo links

### 4. Contact Information
**File: `src/components/Contact.tsx`**
- Lines 20-30: Update contact details (email, phone, location)
- Lines 40-50: Update social media links

### 5. Resume
- Replace `/public/Rishita_Bhatt_Resume.pdf` with your resume file
- Update the filename in the contact component if needed

## 🎨 Design Customization

### Colors
**File: `tailwind.config.js`**
- Update the `primary` and `secondary` color palettes
- Modify the gradient colors in components

### Fonts
**File: `tailwind.config.js`**
- Change font families in the `fontFamily` section
- Update Google Fonts import in `src/app/globals.css`

### Images
- Replace `/public/profile.png` with your profile picture
- Add project images to `/public/` and update paths in Projects component

## 🚀 Deployment Options

### Vercel (Recommended)
1. Push to GitHub
2. Connect to Vercel
3. Deploy automatically

### Netlify
1. Run `npm run build`
2. Deploy the `.next` folder

### Other Platforms
- Any static hosting service that supports Next.js
